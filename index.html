ABOUT

충분합니다.

임원의 생각을 바로 쇼츠로 만듭니다. 기술 설정을 몰라도 자동으로 완성됩니다.

MAKING
1. 주제 적기첫 단계
2. 화면·소리·자막자동
3. 진행률 확인단계+%
4. 완성 영상바로 재생

이 앱은 파이썬(Streamlit) 기반이라 GitHub Pages에서는 소개만 보여주고, 실제 제작은 내려받아 실행합니다.

HOW TO RUN

직접 실행하는 법

이 컴퓨터에서 세 단계면 완성됩니다.

단계안내비고
01
준비소스 받기

저장소를 내려받습니다

git clone 한 뒤 폴더로 들어가면 됩니다.
02
실행한 줄 명령

sh webui.sh 를 실행합니다

브라우저가 http://127.0.0.1:8501 을 자동으로 엽니다.
03
제작주제 입력

주제를 적고 쇼츠 만들기를 누릅니다

오른쪽에 진행률이 단계와 %로 보이고, 완성되면 바로 재생됩니다.
TIP
